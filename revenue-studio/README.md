# Revenue Studio landing page

Static bilingual (Polish/English) landing page for GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive neon-purple design
- `script.js` — language switching, browser-language detection, saved manual choice, mobile navigation
- `assets/revenue-studio-logo.png` — supplied Revenue Studio graphic

## Language
Polish is selected automatically when the browser language starts with `pl`; otherwise English is used. A manual EN/PL selection is saved in localStorage.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.
